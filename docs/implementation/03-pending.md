# Отложенное: живые проверки до появления кредитов и вопросы владельцу

**Единственный реестр** всего, что ждёт (а) кредитов у LLM-провайдеров и (б) слова владельца. Заведён 2026-09-13 по леджерам
срезов А, Б-1, V1, D42, Ш1 и спекам. Правило: новый вопрос владельцу — только сюда, ссылкой на источник (леджер, спека, ревью);
леджеры и спеки — источники, не реестр. Закрытый пункт — вычёркивать здесь же, с датой и ссылкой на носитель.

Состояние на 2026-09-13: у **обоих** провайдеров кредитов нет с 2026-09-02 (OpenAI — HTTP 429 «You have no credits remaining»,
Anthropic — HTTP 400 «Your credit balance is too low»; логи в леджере Б-1 `logs/llm-smoke-*.log`). Следствие: **чат в проде отвечает
отказом провайдера**, рутины (садовник словаря) живьём не работают, все живые приёмки §1 не выполнены.

## 1. Когда появятся кредиты — порядок и носители

Ключи: прод — Render Environment (`sync: false`, runbook §2), локально — `apps/server/.env` (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`,
`ORBIS_LLM_PROVIDER`). Пополнение кредитов ключей не меняет — передеплой не нужен; ротация ключа — Render env + рестарт.
Все скрипты — из корня репозитория (`.env` подхватывается bun'ом), локальная БД поднята (`bun run db:prepare`).
