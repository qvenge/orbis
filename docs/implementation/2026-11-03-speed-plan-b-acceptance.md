### Окружение

- macOS 26.2 x86_64, Bun 1.2.7, Chrome 156.0.8078.80, viewport 1280×860. HTTP Orbis `127.0.0.1:3009`, PostgreSQL 17 в отдельном контейнере `supabase/postgres:17.6.1.140` на loopback `54339`. Серверная роль `orbis_app` — `NOINHERIT`, `NOBYPASSRLS`; планировщик рутин выключен.
- Профиль Chrome выделен для синтетического владельца. Стенд использует локальную HS256-сессию и обычные пути приложения для онбординга и создания фикстур. Это позволяет измерять UI, tRPC, RLS и работу с кешами в браузере. Живой вход и обновление сессии Supabase проверяются отдельно.
- Сценарий разделяет запуск без HTTP/SW-кеша (`cold-shell`), удаление кеша ответов выбранного аккаунта (`empty`), повторный запуск с сохранённым хранилищем (`warm`) и запуск с сетевым режимом offline. Повторный переход в том же JS-контексте измеряется отдельно. На базе до Б постоянного кеша ответов ещё нет.
