**Safari initial-doc коррекция одобрена для единственного rerun root Mac session.** Точный client `0bb5718742ca1bd2bed7dbac495f32c529c3ebbeff8f0c3a6df36fe94e79ac7f`, helper `862d330e9148a44256955716baf656ac95664dc773677dd9ec4b5e34bf653613`, дельта `d0503057efeda0ba3587858a7146ea511b79ee1e128432fd704bcafe547eca4d`. Все пять entries текущего client-манифеста совпали. [Дельта](safari-strict-ack-initial-doc.diff).

В текущем Safari HTTP state нет full bodyDoc, поэтому старый client остановился до arm и ввода. Новый helper проверяет exact own origin, owner и запас срока синтетического credential. Он выполняет реальный same-origin entity.get с body/bodyDoc до arm, использует токен только внутри браузера и возвращает только документ/ревизию и synthetic ID. Client сопоставляет ревизию state и полный документ persisted cache. Последующий 24-секундный барьер ACK/input/GET остаётся прежним, без искусственной вставки input или response. Первый pre-arm KeyError сохраняется. Источник не доказывает успешность нового Safari прогона, а временные automation settings и физический iPhone остаются в прежних границах. [Helper](safari-functional-stand/read-server-body.js).

В этой сверке браузеры, driver, серверы и БД не запускались.
