Постоянная инструкция может фиксировать проверенную локальную серверную последовательность и её точные предварительные ограждения. Перевод живых документов, принудительный недопуск старых cursors/дисковых ответов и безопасное восстановление numeric draft с совпадающей ревизией остаются самостоятельными условиями. Реальные данные, полевая PWA/Safari, внешний Supabase/pooler и production в этой репетиции не использовались. Выпуск, push и локальный main merge остаются вне вердикта. Ревью собственных запусков БД, браузера и тестов не делало.
