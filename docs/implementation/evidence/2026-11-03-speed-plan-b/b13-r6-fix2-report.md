# Б13 R6. Повторное исправление первого открытия с диска

Независимое ревью нашло регрессию при первом открытии с диска. Локальный шаг опирался на A. Первый принятый GET с внешним D объявлял D исходной серверной основой и оставлял шаг активным. Реальное нажатие отправляло старое A с `expectedTitle: D`, и синтетический сервер с проверкой равенства принимал замену D на A. [Независимая проба](b13-r6-review.md).

История записи теперь удерживает один первый неподтверждённый заголовок из канонического raw диска. Дисковая публикация запоминает его для будущего сравнения. Только принятый сетевой ответ может сделать его серверной основой или признать локальные шаги устаревшими. Показанная накладка C не подменяет исходное дисковое A. Первый совпадающий сетевой A сохраняет шаги. Первый внешний D очищает общий и нативный стек, сохраняя грязный ввод. Собственное pending/ACK по-прежнему распознаётся. При первом GET с A, начатом до собственного ACK, серверная основа повышается до подтверждённой и сохраняется атрибуция ACK. Следующий принятый GET с A, действительно начатый после ACK, может доказать внешнее возвращение к A. Маркер диска снимается первой принятой сетевой публикацией, вытеснением LRU или сменой владельца. Сброс только шагов до первого GET сохраняет основу для последующих шагов по этой же записи.

Только четыре из шести согласованных файлов изменились от первого замороженного R6. Это `useTitleHistoryBasis.ts`, `title-history.ts` и два теста. Запросов, новых путей или изменений в runtime, body editor, схеме и дисковом кодеке в этом раунде нет.
