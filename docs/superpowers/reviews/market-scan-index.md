## Раунд 5 — 2026-08-20: ревалидация всех раундов + самостоятельный поиск

По распоряжению владельца все раунды 1–4 перепроверены восемью читателями, плюс два
самостоятельных поиска рынка («правая рука» и граф-life-OS). Вердикты по каждому старому
утверждению, правки и сводный список идей — `reviews/2026-08-20-market-rescan-validation.md`.
Ключевые правки к прежним строкам: у **всех четырёх** продуктов раунда 4 есть политика
подтверждений и/или журнал (наблюдение «ни у кого нет» снято; неразмытое отличие Orbis —
сочетание доменного журнала + Undo + RLS + доменной политики); Orca расшифровывает ADE как
«**Agent** Development Environment» (не «Agentic»); рамка Buzz «групповой чат» занижена
(релей + форж + workflow, свой `buzz-agent` — дефолт); оговорка про docs bb снята (контракт
опубликован npm-SDK и скиллом); мобильная поверхность — у 4/4. «Pull-модели нет ни у кого» —
держится для оболочек, с оговоркой: pull формализован на уровне протокола (MCP 2026-07-28,

## Методологический раунд — 2026-08-14: инструменты SDD

GitHub Spec Kit, Kiro (AWS), OpenSpec, Tessl, fiberplane/drift — разобраны при независимом
ревью дизайна ADE-среза 1; ссылки тогда не сохранялись. Взято: подтверждение формы «спека →
план → задачи» и самого понятия дрейф-гейта между документом и кодом. Разбор —
`reviews/2026-08-14-ade-slice1-design-review.md`.

**Ревалидация 2026-08-20:** форма SDD держится (Spec Kit 130k★, OpenSpec — граф артефактов
с гейтами архивации). Две правки: **Tessl больше не SDD-референс** — пивот в «Agent Enablement
Platform» (реестр скиллов; слово «spec» с главной исчезло; новая роль релевантна D36, не Р1/Р2);
**fiberplane/drift заморожен** (релизов нет с 08.04.2026 — прецедент годен, инструмент нет).
Обоснование Р2 «двусторонней связки критериев с тестами нет ни у кого» опровергнуто (Kiro PBT
с 11.2025); узкая формулировка держится: якорной связки по контент/AST-хешу нет ни у кого.
Детали — `reviews/2026-08-20-market-rescan-validation.md`, II.1.
