# legacy-1v

Экраны Бюджета (обзор, категория, «Новый месяц», транзакции), импорта выписки и Повестки — до среза 1в.

Спека 1б §8.6: код экранов остаётся в репозитории, но недоступен из интерфейса; §15 (реестр временных
отступлений): удаляет срез 1в, который приносит приложения «Бюджет» и Повестку. РП-31 плана 1б.

Каталог исключён из `tsconfig` (`apps/web/tsconfig.json`), vitest (`apps/web/vite.config.ts`), biome
(`biome.json`) и сборки (роутер его не импортирует). Код написан на навигацию 1а (вкладки) и не
компилируется с навигацией 1б — это ожидаемо. Живые помощники, которые экраны экспортировали, остались
в `src/features/*`.
